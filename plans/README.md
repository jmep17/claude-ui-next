## Corrections made to the draft roadmap (so nobody re-derives them)

- Draft said plugin skills are under `plugins/cache/*/skills/` — wrong. They live at
  `<installPath>/skills/**/SKILL.md` where `installPath` comes from
  `~/.claude/plugins/installed_plugins.json` (format v2), and skill dirs can be nested one level
  (e.g. `skills/productivity/handoff/SKILL.md`). `~/.claude/skills/` holds only user skills.
- Draft said to scope highlight.js theme CSS to `data-theme` — wrong. Fumadocs' RootProvider uses
  next-themes with `attribute: "class"`; dark mode is the `.dark` class on `<html>`
  (verified in `node_modules/fumadocs-ui/dist/provider/base.js:55`).
- Draft said history project slug = `project.replaceAll('/', '-')` — incomplete. `.` is also
  replaced (`/Users/jorden/.claude` → `-Users-jorden--claude`). Use
  `project.replace(/[^a-zA-Z0-9]/g, '-')` and verify the directory exists before linking.
- `history.jsonl` timestamps are epoch **milliseconds** (numbers), transcript entry timestamps are
  ISO 8601 **strings**. Don't mix them up.
